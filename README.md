# 잘 먹었습니다!

> 오늘은 같이 저녁 먹을 수 있을까?

가족 단톡방에 올라온 저녁 메뉴에 **5초 안에** 대답하며 일주일을 보내는 텍스트 기반 생활 시뮬레이션입니다.
설치 없이 브라우저에서 바로 돌아가는 단일 HTML 파일(`index.html`)로 만들어졌습니다.

- 1회 플레이: 게임 속 월요일 ~ 일요일
- 목표 플레이 시간: 15~30분
- 모바일 우선 웹 (데스크톱에서는 중앙 카드로 표시)

---

## 어떤 게임인가요

매일 오후 6시, 가족 단톡방에 오늘의 저녁 메뉴가 올라옵니다.
가족들의 메시지가 모두 도착하면 **5초 타이머**가 시작되고, 그 안에 답해야 합니다.

```
엄마  오늘 저녁 먹어?
엄마  오늘은 김치찌개야.
아빠  나 오늘 회식이라 늦어.

5초 안에 답장하기   ■■■■■   5

1  저 먹어요!
2  나 오늘 약속 있어.
3  조금 늦게 먹을게.
```

가족과 먹으면 **식탁 온기**가, 내 약속을 지키거나 좋아하는 음식을 먹으면 **나의 충전**이 채워집니다.
두 지표는 **한 번 채우면 줄어들지 않습니다.** 감점도, 실패도 없습니다.
한정된 일주일 동안 어느 쪽을 더 채울지 고르는 것이 이 게임의 전부입니다.

답장을 놓쳐도 벌점은 없습니다. 그날 채울 수 있었던 칸을 얻지 못할 뿐입니다.

## 플레이 방법

### 바로 하기

저장소의 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

```bash
git clone https://github.com/kigizz1902-beep/ThanksMeal.git
cd ThanksMeal
open index.html          # macOS
# 또는 로컬 서버로
python3 -m http.server 8000   # → http://localhost:8000
```

> GitHub Pages로 배포하려면 저장소 **Settings → Pages**에서 `main` 브랜치의 `/ (root)`를 지정하세요.
> `index.html`이 저장소 루트에 있어 추가 설정 없이 동작합니다.

### 조작

| 입력 | 동작 |
|---|---|
| 숫자키 `1` `2` `3` | 5초 응답 선택 |
| `Enter` | 화면의 주요 버튼 실행 |
| `Esc` | 열린 창 닫기 |
| 터치 / 클릭 | 모든 조작 가능 |
| 우측 하단 `»` | 대사 빨리 보기 |

## 게임 규칙

### 한 주의 흐름

1. **준비 1/3 — 음식 취향**: 좋아하는 음식군 2개, 싫어하는 음식군 1개, 못 먹는 재료 1개
2. **준비 2/3 — 개인 약속**: 일주일에 3개 배치, 그중 1개는 `★ 중요한 약속`
3. **준비 3/3 — 이번 주 저녁표**: 7일치 메뉴 확인 (2일은 당일에 바뀔 수 있음)
4. **월~일 진행**: 오늘의 저녁 → 오후 6시 단톡방 → 5초 응답 → 식탁 결과
5. **일요일 밤**: 주간 결산과 엔딩

### 두 개의 그릇

| 지표 | 표시 | 채우는 방법 |
|---|---|---|
| 식탁 온기 | ❤️ ×5 | 가족과 저녁 먹기, 약속을 미루고 함께하기, 넷이서 한 끼 |
| 나의 충전 | ⭐ ×5 | 개인 약속 참석, 좋아하는 메뉴 먹기, 넷이서 한 끼 |

두 지표 모두 0에서 시작해 **0.5칸 단위**로 채워지며 최대 5입니다.

### 행동별 보상

| 선택 | 식탁 온기 | 나의 충전 | 식사 횟수 |
|---|---:|---:|---:|
| 가족과 저녁 먹기 | +0.5 | — | +1 |
| 좋아하는 메뉴를 먹었을 때 | +0.5 | 추가 +0.5 | +1 |
| 약속을 미루고 가족과 먹기 | +1 | — | +1 |
| 조금 늦게 합류 | +0.5 | 약속이 있으면 +0.5 | +1 |
| 개인 약속 참석 | — | +1 (중요한 약속 +1.5) | — |
| 네 식구가 모두 모인 날 | 추가 +0.5 | 추가 +0.5 | — |
| 답장을 놓침 | — | 약속이 있으면 절반만 | — |

주간 목표인 **가족 저녁 3회**를 달성하면 결산에서 식탁 온기 +0.5 보너스를 받습니다.

### 게임 방법 안내

첫 플레이에서 `일주일 시작하기`를 누르면 2:3 비율의 안내 카드 4장이 먼저 나옵니다.
`건너뛰기` / `이전` / `다음` / `게임 시작` 버튼과 점 표시 4개로 넘기며, 모바일에서는 좌우 스와이프로도 넘길 수 있습니다.
한 번 본 뒤에는 자동으로 뜨지 않고, 타이틀의 `게임 방법` 버튼으로 언제든 다시 볼 수 있습니다.

### 엔딩

결산에서 8가지 엔딩 중 하나가 나옵니다. **위에서부터 먼저 검사**하고, 처음 맞는 조건의 엔딩이 선택됩니다.

| 순위 | 엔딩 | ID | 조건 |
|---:|---|---|---|
| 1 | 나를 기억한 한 그릇 | `remembered-bowl` | 좋아하는 메뉴 식사 2회 이상 + 못 먹는 재료 배려 1회 이상 + 온기 3 이상 |
| 2 | 모두 함께 외식하는 날 | `family-outing` | 8회차 이상 + 외식 이벤트 발생 + 외식에 참여 |
| 3 | 아빠의 저녁 식탁 | `dads-table` | 아빠 요리 주간 + 그날 저녁에 참여 |
| 4 | 함께라서 따뜻한 한 주 | `warm-week` | 가족 식사 5회 이상 + 온기 4 이상 |
| 5 | 딱 좋은 거리 | `balanced-distance` | 가족 식사 3~4회 + 지킨 약속 1개 이상 + 온기 3 이상 + 충전 2.5 이상 |
| 6 | 나를 위한 일주일 | `my-week` | 가족 식사 3회 미만 + 지킨 약속 2개 이상 + 충전 4 이상 |
| 7 | 기다려준 식탁 | `waiting-table` | 가족 식사 3회 미만 + 답장 성공률 80% 이상 + 온기 1.5 이상 |
| 8 | 조금 엇갈린 한 주 | `missed-week` | 그 외 (실패가 아니라 다음 주로 이어지는 결말) |

엔딩 화면에는 결과에 맞는 정사각형 일러스트 한 장과 함께 `가족과 함께 먹은 횟수 · 지킨 개인 약속 · 답장 성공률 · 최종 가족 온기 · 획득한 엔딩`이 표시되고, 그 주의 행동을 요약한 문구(`넷이서 한 끼` 등)가 붙습니다.
`모은 엔딩 보기`에서 지금까지 만난 엔딩을 확인할 수 있습니다 (아직 못 만난 엔딩은 `???`).

조건을 바꾸려면 `index.html`의 `ENDING_DEFS` 배열에서 해당 항목의 `test(c)`만 수정하면 됩니다. `c`는 `endingContext()`가 만든 객체입니다.

### 반복 플레이 해금

완주 기록은 새 게임을 시작해도 사라지지 않습니다. 타이틀의 `기록 보기`에서 확인할 수 있습니다.

| 해금 | 조건 | 내용 |
|---|---|---|
| 아빠 요리 주간 | 1회차부터 | 주 40% 확률로 하루, 아빠가 요리하고 단톡방 첫 메시지를 보냅니다 |
| 돌발 메시지 | 4회차부터 | 주 30% 확률, 답장이 늦게 도착하는 숨은 이벤트 6종 (보상에는 영향 없음) |
| 가족 외식 | 8회차부터 | 8회차에 반드시 1회, 이후 주 35% 확률로 주말에 발생 |

## 디자인

> 가족의 일주일을 다이어리 한 페이지처럼 넘겨보는, 검은 펜선과 노란 형광펜으로 만든 따뜻한 생활 시뮬레이션.

- **종이색 + 먹색 + 노랑**: 노란색은 선택·새 알림·주요 행동·보상에만 사용합니다.
- **2px 펜선과 6px 모서리**: 그림자 대신 선으로 구분하고, 과한 둥근 모서리와 입체 버튼을 쓰지 않습니다.
- **DosGothic 한 벌**: 제목·본문·버튼·숫자를 한 서체로 통일하고, 강조는 굵기 대신 크기·테두리·노란 배경으로 합니다.
- **색 없이도 읽히는 상태**: 참석/늦게/불참은 텍스트로도 구분되고, 지표에는 `2.5/5` 같은 실제 수치를 함께 제공합니다.
- **비난보다 온기**: 붉은 경고, 실패 팝업, 깨지는 하트를 쓰지 않습니다.

자세한 규칙은 [DESIGN.md](DESIGN.md)에 있습니다.

### 접근성

- 모든 터치 영역 44×44px 이상, 본문 최소 15px
- 아이콘 버튼에 `aria-label`, 지표에 실제 수치 텍스트 제공
- 타이머는 시작과 2초 남음만 음성으로 알림 (매초 읽지 않음)
- `prefers-reduced-motion`에서 이동·확대 애니메이션 제거
- 키보드만으로 준비부터 엔딩까지 플레이 가능

```
index.html                         게임 본체 (HTML·CSS·JS 단일 파일, 의존성 없음)
DESIGN.md                          디자인 가이드 (색상·타이포·화면별 명세)
잘먹었습니다_PRD.md                 v0.1 기획서
잘먹었습니다_PRD_v0.2_수정사항.md    v0.2 기획 변경 사항
ASSET_MANIFEST.md                  그림 리소스 명세
assets/thanksmeal/ui-v2/           가족 얼굴·코어 아이콘·타이틀 로고
assets/thanksmeal/tutorial/        게임 방법 안내 4장 (2:3)
assets/thanksmeal/endings/         엔딩 일러스트 8장 (1:1)

```

이미지는 모두 저장소 안의 상대 경로(`assets/...`)로 불러오므로 빌드 도구 없이 그대로 동작합니다.
불러오기에 실패하면 깨진 이미지 대신 대체 문구가 표시됩니다.
(웹폰트만 CDN에서 불러오며, 실패해도 시스템 고딕으로 대체되어 레이아웃이 유지됩니다.)

### 저장 데이터

브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

| 키 | 내용 |
|---|---|
| `jalmeogeoss_save_v2` | 진행 중인 한 주 (새 게임 시작 시 삭제) |
| `jalmeogeoss_meta_v1` | 누적 플레이 횟수, 게임 방법 확인 여부(`tutorialSeen`), 획득한 엔딩(`endingsFound` — 중복 제거, 획득 회차·날짜 포함), 외식/돌발 해금 여부 (새 게임을 시작해도 유지) |

- 빌드 도구·프레임워크·패키지 의존성 없음 (단일 HTML)
