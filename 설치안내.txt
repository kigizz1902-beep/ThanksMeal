========================================
  잘 먹었습니다! - 설치 안내서
  우리 가족 감사 식탁 게임
========================================

■ 시스템 요구사항
  - macOS 10.12 이상 또는 Windows 10 이상
  - 저장 공간: 약 200MB

────────────────────────────────────────

■ macOS 설치 방법

  1. "잘 먹었습니다-1.0.0-universal.dmg" 파일을 더블클릭합니다.
  2. 열린 창에서 앱 아이콘을 Applications(응용 프로그램) 폴더로 드래그합니다.
  3. Applications 폴더에서 "잘 먹었습니다" 앱을 실행합니다.

  ※ 최초 실행 시 보안 경고가 나타날 수 있습니다.
     → 앱을 우클릭(또는 Control+클릭) > "열기" 선택
     → "열기" 버튼을 다시 클릭하면 실행됩니다.

  ※ 삭제 방법: Applications 폴더에서 앱을 휴지통으로 이동

────────────────────────────────────────

■ Windows 설치 방법

  1. "잘 먹었습니다 Setup 1.0.0.exe" 파일을 더블클릭합니다.
  2. 설치가 자동으로 진행됩니다.
  3. 설치 완료 후 바탕화면 또는 시작 메뉴에서 실행합니다.

  ※ "Windows의 PC 보호" 경고가 나타날 수 있습니다.
     → "추가 정보" 클릭 > "실행" 버튼을 클릭하면 설치됩니다.

  ※ 삭제 방법: 설정 > 앱 > "잘 먹었습니다" 선택 > 제거

────────────────────────────────────────
